# Тесты целостности данных

Структура и смысл таблиц датасета описаны в файле `datapackage.json` по стандарту
[Frictionless Data Package v2](https://datapackage.org): для каждой таблицы указаны поля,
их типы и описания, допустимые значения категориальных полей, обязательные и уникальные
поля, связи между таблицами.

Тесты проверяют, что данные соответствуют этому описанию. Для запуска нужен Python 3
и пакеты из `requirements.txt`:

    pip install -r tests/requirements.txt
    python -m pytest tests

(команды выполняются в папке датасета).

## Общие проверки (`test_package.py`, `dvcheck.py`)

Одинаковы для всех датасетов Репозитория.

- `test_descriptor`: файл `datapackage.json` читается и соответствует стандарту.
- `test_resource`: каждая таблица соответствует своей схеме — значения имеют указанный тип,
  обязательные поля заполнены, уникальные значения не повторяются, ссылки на другие таблицы
  (внешние ключи) указывают на существующие строки, во всех строках одинаковое число ячеек.
- `test_categories`: в категориальных полях встречаются только значения из списка
  `categories`, то есть каждое значение записано единообразно.
- `test_whitespace`: в ячейках нет пробелов в начале и в конце значения.

## Проверки этого датасета

Таблицы `csv/vol_N.csv` целиком порождаются парсером из текстовых файлов `txt/vol_N.txt`,
поэтому ошибки распознавания и служебная разметка текстов могут попасть в значения полей.
`test_data.py` проверяет каждую таблицу на такие ошибки (`test_values[таблица-проверка]`):

- `no_markup`: в текстовых полях нет разметки txt-файлов — заголовков алфавитных разделов
  `<letter>…</letter>` и знаков ручного разбора записей `#` и `@`.
- `no_ocr_junk`: нет знаков `^` и `<`, которыми при распознавании заменялись нечитаемые символы.
- `tail_has_text`: непустое поле `tail` содержит хотя бы одну букву или цифру, т. е. это
  действительно нераспределенный фрагмент записи, а не остаток распознавания («„», «*», «.»).
- `author_final_period`: из `author` снята завершающая точка записи (README, «Формат
  данных»): значение не оканчивается на «).», «].», удвоенную точку или точку через пробел,
  стандартное значение — «Имя авт. не установлено» без точки.
- `author_no_latin_lookalikes`: в именах авторов, записанных кириллицей, нет латинских букв,
  неотличимых от русских (`X` вместо `Х`, `A` вместо `А` и т. п.), — иначе имя не найдется
  поиском и не сопоставится с указателем имен (т. 7). Значения с настоящими латинскими
  буквами («N. N.», «A. S.», «IPS-E.») проверку проходят.
- `line_range`: `end` ≥ `start`; у записи-заполнителя для номера, пропущенного в источнике
  (`tail` = `MISSING`), `end` = `start` − 1.
